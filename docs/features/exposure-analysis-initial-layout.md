# Exposure Analysis — Initial Layout & Mock Data

**File:** `apps/web/src/pages/ExposureAnalysis.tsx`

## Change Summary

Created the `ExposureAnalysis` page from scratch with a structured layout and mock data, establishing the visual foundation for the security exposure dashboard.

## Rationale

The product needed a dedicated page to monitor and visualize security exposure across domains, infrastructure, and cloud storage. The initial implementation focused on getting the layout right with placeholder data before wiring up real backend data.

## Implementation Details

### Layout Structure

The page was built using the shared `PageLayout` component for consistent theming:

- **Header:** Title, subtitle, and a live-status badge in `headerContent`.
- **Hero Section:** A two-column grid (`xl:grid-cols-[1fr_360px]`) containing:
  - **Left column:** Target selector dropdown, time-range tabs, exposure score display, and a trend chart.
  - **Right column (Action Panel):** Surface mode toggle (External/Internal), Assets Monitored card, Open Findings card, CTA buttons (Run Full Scan, Connect Integration), and an Attack Surface Health panel.
- **Bottom Section:** A "Top Exposed Assets" table with columns for Asset, Category, Status, Score Impact, Detected, and Action.

### Mock Data

Several mock data structures were defined to populate the UI:

- `MONITORED_TARGETS` — Three sample targets (domain, IP, S3 bucket).
- `TIME_RANGES` — Array of time range options (`1h`, `24h`, `1w`, `1m`, `6m`, `1y`).
- `TREND_DATA` — A `Record<TimeRange, TrendPoint[]>` generated by a `gen()` helper function producing deterministic sine-based wobble for scores and findings counts.
- `TOP_EXPOSED_ASSETS` — A static array of sample exposed assets for the bottom table.
- `COVERAGE_STATS` — Mock coverage statistics for the health panel.
- `currentScore` / `scoreChange` — Mock score value and delta for the hero section.

### State Management

Initial state hooks:

```typescript
const [timeRange, setTimeRange] = useState<TimeRange>('1m');
const [surfaceMode, setSurfaceMode] = useState<SurfaceMode>('external');
const [targetOpen, setTargetOpen] = useState(false);
const [selectedTarget, setSelectedTarget] = useState(MONITORED_TARGETS[0]);
```

### Chart

The initial chart used `recharts` with a `ComposedChart` containing `Bar`, `Area`, `XAxis`, `YAxis`, `Tooltip`, and a custom `CustomTooltip` component rendered inside a `ResponsiveContainer`.

### Theming

The page adhered to the light theme established by `PageLayout`:
- White cards with `rounded-3xl border border-slate-100 bg-white shadow-md`.
- Slate text hierarchy (900 for headings, 400-500 for secondary).
- Brand accent color `#00C2CB` (teal) for interactive elements.
- `#EF4444` (red) for critical/danger indicators.

## Impact

This established the complete visual scaffold for the Exposure Analysis page. All subsequent changes (waveform chart, live data, polling, scan) were built on top of this layout.
