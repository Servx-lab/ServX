# Domain: Exposure Analysis

**Route:** `/api/exposure`  
**Location:** `apps/api/src/domains/exposure/`

This domain handles the Main-UI retrieval and initiation of codebase scans. It interfaces with the findings generated by the **Exposure Analysis** microservice.

## Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| `GET`  | `/summary` | `requireAuth` | Aggregates high-level statistics of exposure findings for the tenant. |
| `GET`  | `/findings` | `requireAuth` | Retrieves the paginated list of vulnerability and configuration findings. |
| `GET`  | `/assets` | `requireAuth` | Lists the cloud assets currently being monitored. |
| `POST` | `/assets` | `requireAuth` | Registers a new cloud asset for exposure monitoring. |
| `POST` | `/scan` | `requireAuth` | Manually triggers a remote scan against a monitored repository. |

*Note: All endpoints are strictly tenant-scoped and require a valid Supabase session.*
